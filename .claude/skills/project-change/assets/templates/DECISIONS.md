# Decisions

Lightweight architecture decision records. One entry per decision that had a viable alternative — a change with no fork in the road had no decision, and does not belong here.

Newest first. Never edit a past entry to make it look better; supersede it with a new one and link back. The value of this file is that it records what was believed at the time.
